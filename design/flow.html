Landing page designed
  • What it is, who it is for, one screenshot of the dashboard.
  • Primary action: Start tracking → register.
  • Secondary: log in (for people who already have an account).
  • No data, no auth. Static.
Authenticate designed
  • Register: name, email, password → POST /auth/register.
  • Login: email, password → POST /auth/login.
  • Session restores on every page load via refresh cookie → POST /auth/refresh then GET /auth/me.
  • Errors shown inline per field; rate limited on the server.
  • After success → sites list.
Sites list home after login
  • Card per site: name, domain, active/inactive, quick stat.
  • Empty state is the important one: one big Create site.
  • Action: create site. Click a card → that site's dashboard.
  • Data: GET /sites.
Create site form
  • Two fields: name, domain. Nothing else.
  • POST /sites → returns a tracking ID.
  • Straight into setup — never dump the user back on a list.
Setup install
  • Copy-paste script snippet with the site's tracking ID.
  • Copy button; snippet is the hero of the page.
  • Live waiting state: "listening for your first event" → flips to success when one arrives.
  • Reachable later as a tab on the site, not only at creation.
Site dashboard the main page
  • Header: site name, domain, active badge. Tabs: Analytics · Setup · Settings.
  • Range picker: 7d / 30d / 90d, hourly or daily.
  • Realtime strip — active now, pageviews, visitors, active pages, live referrers (/analytics/:id/realtime/stream).
  • Totals: pageviews, sessions, unique visitors (/overview).
  • Traffic over time, area chart (/timeseries).
  • Top pages and top referrers, side by side.
  • Devices (browser / OS / device) and countries.
  • States each block needs: loading skeleton, empty, error.
Site settings per site
  • Edit name and domain (PUT /sites/:id).
  • Tracking ID shown; regenerate key (POST /sites/:id/regen-key) — warns that the old snippet stops working.
  • Plan / rate limit tier, read-only for now.
  • Danger zone: delete site, typed confirmation.
Account per user
  • Name and email (PATCH /auth/me).
  • Change password.
  • Log out.
